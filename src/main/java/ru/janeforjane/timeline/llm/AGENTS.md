# Правила модуля llm

Это правило действует только в папке llm/ — подгружается, когда агент работает
с файлами этого модуля, и не видно в остальном проекте.

## Требования модуля
- Вызовы LLM разрешены ТОЛЬКО здесь (в llm/), и только через сервисный слой.
- Каждый внешний вызов — с таймаутом.
- Всегда реализуй fallback: если LLM недоступна — шаблонные ветки по правилам.
- Ответ LLM парси в DTO через structured output, не работай с сырой JSON-строкой.
