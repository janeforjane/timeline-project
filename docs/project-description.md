# timeline-project — описание

## Что это
Веб-приложение для визуализации дерева последствий при принятии решений.
Пользователь вводит одно решение (например, «Согласиться на повышение с переездом»).
Система строит граф: от решения отходят две ветки-последствия, от каждого
последствия — новая развилка (два варианта), и так до 3 уровней глубины.
В конце пользователь получает «карту своей временной линии» — артефакт,
который можно сохранить.

## Эстетика
TVA из сериала «Локи»: тёмный фон, золотая «священная линия», синие/зелёные
ветки-ответвления, ретро-терминал с надписями «ВРЕМЕННОЕ УПРАВЛЕНИЕ.
ВЕТВЛЕНИЕ ОБНАРУЖЕНО». Монохромные линии, светящиеся узлы.

## Функционал (MVP)
1. Экран ввода решения (текстовое поле + кнопка «Построить линию»).
2. Экран графа: корень → 2 ветки → 4 последствия → 8 финалов (глубина 3, ширина 2).
   Клик по узлу → панель с текстом последствия и кнопкой «Продолжить эту ветку».
3. Экран «Карта линии»: сохранённый граф + итог («+деньги, −время, −удовольствие»).
4. История сохранённых линий (список).

## Стек
- Java 17, Spring Boot 3, Maven
- PostgreSQL (3+ таблицы: decision, node, edge)
- Thymeleaf/HTMX или минимальный JS-фронт (без тяжёлого React)
- LLM: российский агрегатор (OpenAI-совместимый API), structured output
- Деплой: TimeWeb Cloud (VPS), Docker не обязателен для MVP

## AI-фича
- Генерация веток: на каждый клик по узлу LLM возвращает
  `{branches: [{consequence, next_dilemma?}], final_summary?}`.
- На уровне 3 — `final_summary` вместо `next_dilemma`.
- Контроль стоимости: кэш по хэшу (узел + уровень), лимит вызовов на сессию.
- Fallback: если LLM недоступна — шаблонные ветки по правилам.

## Ограничения
- Глубина дерева — 3 уровня, ширина — 2 ветки (чтобы не утонуть).
- Один LLM-вызов на узел (не «всё дерево сразу»).
- Без WebSocket/реального времени (это не игра, а инструмент).
