Пользователь внёс изменения не на той ветке. Нужно оформить их в отдельную ветку.

Порядок:
1. Выполни `git status --short` и `git branch --show-current`.
   Покажи текущую ветку и ПОЛНЫЙ список изменённых файлов (staged + unstaged + untracked).
2. Если имя новой ветки не передано в `$ARGUMENTS` — спроси его у пользователя.
3. Покажи итог: «Переношу эти N файлов из <текущая> в ветку <name>. Продолжить?» — дождись подтверждения.
4. После подтверждения выполни `git switch -c <name>`.
5. Проверь `git status`, что изменения теперь на новой ветке.
6. НЕ коммить и НЕ пушь. Если ветка `<name>` уже существует — остановись и спроси, что делать.
